This site contains precompiled wheels used by Android version of NPPS4.

Packages are compiled with these options:

  • 16KiB page size.
  • Targets Python 3.14.
  • arm64-v8a and x86-64 ABI.
  • Android 7.0 or later (API 24).

The repository can be found in GitHub.
